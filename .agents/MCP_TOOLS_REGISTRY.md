# 🛠️ Catálogo de Ferramentas MCP (Model Context Protocol)

As ferramentas abaixo estão registradas no barramento `McpServerRegistry` e podem ser acionadas autonomamente pelo `CognitiveOrchestrator`.

| Nome da Ferramenta | Categoria | Descrição |
|-------------------|-----------|-----------|
| `network_scan` | Network | Escaneia a rede local (Wi-Fi/Ethernet) e retorna os nós e dispositivos ativos. |
| `stealth_search` | StealthBrowser | Realiza busca furtiva na web com evasão anti-bot. |
| `stealth_extract_url` | StealthBrowser | Extrai o conteúdo limpo do DOM em Markdown. |
| `docker_execute_code` | Sandbox | Executa código isolado dentro de container Docker temporário. |
| `calendar_get_upcoming` | Calendar | Obtém os próximos compromissos do Google Calendar. |
| `email_get_recent` | Email | Obtém e-mails recentes da caixa de entrada. |
| `google_gmail_send` | GoogleServices | Envia e-mails formatados via conector Google/Gmail. |
| `spotify_get_current` | Spotify | Obtém o status de reprodução e música atual no Spotify. |
| `spotify_play` | Spotify | Reproduz faixas ou playlists no Spotify. |
| `spotify_search` | Spotify | Pesquisa por faixas e artistas no Spotify. |
| `onedrive_list_files` | Files | Lista arquivos e diretórios do OneDrive. |
| `get_geolocation_weather` | Geolocation | Obtém a localização e clima em tempo real. |
| `self_evolve_codebase` | CodeEvolution | Altera o próprio código da Sexta-Feira com validação `dotnet build` em tempo real. |
